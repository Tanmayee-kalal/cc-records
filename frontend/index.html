01 — OVERVIEW

Project Overview

This project demonstrates the development and deployment of a containerized microservice application using Docker and Docker Compose, followed by performance evaluation using ApacheBench.

Architecture

Three independent REST-based microservices working together.

Containerization

Each service is deployed independently using Docker containers.

Networking

Docker Compose provides a shared network for service communication.

Performance

ApacheBench is used to test different workload levels.

10 — ANALYSIS

Performance Analysis

Throughput

Throughput increased from 52.11 req/s to 250.05 req/s as concurrency increased.

Response Time

Average response time increased from 19.191 ms to 63.986 ms at higher concurrency.

Reliability

All five workload levels completed with 0 failed requests.

Memory

Memory usage was more significant than CPU usage, with the Payment Service reaching approximately 58.66 MiB.

11 — CONCLUSION

Containerized. Connected.
Tested. Analyzed.

The three Flask microservices were successfully containerized and deployed. Docker Compose enabled shared networking and service-name communication. All five workloads completed with zero failures, while throughput increased and response time increased at higher load.
